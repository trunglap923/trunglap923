### InsightAI — Agentic GraphRAG Knowledge Base

An Agentic GraphRAG system for multi-document question answering using
**knowledge graphs, semantic retrieval, and LLM-based orchestration**.

- Built a **LangGraph-based agentic workflow** with dynamic intent routing
- Combined **Neo4j GraphRAG** with semantic vector retrieval using **Milvus**
- Supported **multi-hop reasoning** across entities and relationships
- Added **LLM-as-a-Judge evaluation** and Web Search fallback
- Built an asynchronous ingestion pipeline with **Celery and Redis**

**Tech Stack:**  
`Python` `FastAPI` `LangGraph` `Neo4j` `Milvus` `Celery` `Redis`

### AI Nutrition Assistant & Graph-based RAG Chatbot

An AI-powered nutrition assistant for personalized meal planning and health-related question answering.

- Designed a **graph-based RAG workflow** using LangGraph
- Fine-tuned **BGE-M3 embeddings with QLoRA and contrastive learning**
- Integrated domain-specific embeddings into **Elasticsearch**
- Built a constraint-based meal optimization engine using **SLSQP**
- Designed the system using a **microservices architecture**

**Tech Stack:**  
`Python` `FastAPI` `LangGraph` `BGE-M3` `Elasticsearch` `Sentence Transformers` `Docker`

### Real-time Vehicle Tracking & License Plate Recognition

A real-time computer vision system for vehicle tracking and automatic license plate recognition.

- Vehicle detection using **YOLOv8**
- Multi-object tracking using **DeepSORT**
- License plate OCR using **PaddleOCR**
- Built a **microservices architecture** with gRPC
- Real-time inference using **FastAPI and WebSocket**
- Achieved approximately **25 FPS**

**Tech Stack:**  
`Python` `YOLOv8` `DeepSORT` `PaddleOCR` `FastAPI` `gRPC` `WebSocket` `MongoDB`
